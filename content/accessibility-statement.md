# Accessibility Statement

This statement applies to the EAA Accessibility Hub, a reference site
covering EN 301 549 and the European Accessibility Act (EAA).

We want as many people as possible to be able to use this site. That
means you should be able to:

- navigate using just a keyboard
- navigate using a screen reader
- zoom in up to 400% without loss of content or function
- resize text using your browser's own font size or zoom controls,
  without loss of content or function

## Conformance status

This site is designed and built to conform to **WCAG 2.1 Level AA** — the
same standard EN 301 549 references. As a small, actively developed
project, we treat this as a target we continuously test against rather
than a one-off certification.

## Technical specifications

The site is built with semantic HTML, and relies on CSS and JavaScript
for layout and enhancement only — content and navigation remain usable
if either is limited.

## Reporting accessibility problems

If you find a problem not listed here, or think we're not meeting
accessibility requirements, please get in touch via the contact details
on this site so we can look into it.

## Preparation of this statement

This statement was last reviewed in 2026. It will be reviewed again as
the site's content and features change.
